## 🚀 Getting Started

### Prerequisites
- **Python 3.8+**
- **Jupyter Notebook / JupyterLab** (to run `.ipynb` files)

### Running Python Scripts
You can execute any standard Python solution directly using:
```bash
python leetcode/"1022.Sum of Root To Leaf Binary Numbers.py"
```

### Running Jupyter Notebooks
Launch Jupyter Notebook to view and interact with algorithm demonstrations:
```bash
jupyter notebook
```
